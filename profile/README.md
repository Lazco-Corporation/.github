## [Rich Model Selector](https://github.com/Lazco-Corporation/pi-rich-model-selector)
[![](https://img.shields.io/npm/v/@lazco-studio/pi-rich-model-selector.svg?color=blue)](https://www.npmjs.com/package/@lazco-studio/pi-rich-model-selector) [![](https://img.shields.io/npm/last-update/@lazco-studio/pi-rich-model-selector.svg)](https://github.com/Lazco-Corporation/pi-rich-model-selector/commits/main) [![](https://img.shields.io/npm/dm/@lazco-studio/pi-rich-model-selector?color=E4BD68)](https://www.npmjs.com/package/@lazco-studio/pi-rich-model-selector) [![](https://img.shields.io/npm/l/@lazco-studio/pi-rich-model-selector.svg?color=e3e3e3)](https://www.gnu.org/licenses/agpl-3.0.html)

A model picker for the pi coding agent.
It shows the context size, the price, the thinking level, and the key state of each model.
You can star a model, hide a model, and sort your starred models in your own order.

***🌟 The project is available as [@lazco-studio/pi-rich-model-selector npm package](https://www.npmjs.com/package/@lazco-studio/pi-rich-model-selector).***

[![](https://github-readme-stats.on-cloud.eu.org/api/pin/?username=Lazco-Corporation&repo=pi-rich-model-selector&show_owner=true&theme=onedark)](https://github.com/Lazco-Corporation/pi-rich-model-selector)
